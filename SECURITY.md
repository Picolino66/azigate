# Política de segurança

## Reporte privado

Não abra uma issue pública para vulnerabilidades ou credenciais expostas. Use **Security > Report a vulnerability** no repositório GitHub ou contate privadamente o proprietário do repositório.

Inclua versão/commit, impacto, passos mínimos de reprodução e uma sugestão de correção. Não inclua chaves reais, prompts, código privado de usuários ou dados obtidos de terceiros.

## Versões suportadas

A versão presente na branch principal é a única suportada. Atualizações de segurança devem ser aplicadas ao deploy assim que os quality gates forem concluídos.

## Expectativa de resposta

O mantenedor deve confirmar o recebimento em até 3 dias úteis, classificar o risco e coordenar correção/divulgação responsável antes de qualquer publicação.
