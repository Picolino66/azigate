# Skills usadas

- `autonomous-software-orchestrator`: coordenação, ADRs, rastreabilidade e gates.
- `defensive-security-auditor` (complementar): modelo de ameaças, revisão de API, secrets, dependências, Docker e Nginx.

Não há skill local de implementação Fastify mais especializada; o backend é executado pelo módulo interno de engenharia do orquestrador.
